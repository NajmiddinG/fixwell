# AI Usage

AI assistance was used for:
- initial project scaffolding
- model and serializer boilerplate
- API route wiring
- validation and conflict-check planning
- test-case suggestions
- README and documentation drafting

The following areas were manually reviewed and refined:
- business logic boundaries
- booking status transitions
- availability calculations
- working-hour restrictions
- authorization checks
- transaction and lock strategy
- final regression testing

The developer should understand every generated component before final submission and should treat this project as a reviewed implementation rather than a blindly accepted scaffold.
